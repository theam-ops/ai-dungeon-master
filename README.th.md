เกมสวมบทบาทแนว D&D ที่มี AI เป็นผู้คุมเกม มันเล่าเรื่อง สวมบทบาท NPC ทุกตัว และตัดสิน
ตามกติกา — แต่ลูกเต๋า พลังชีวิต และค่าประสบการณ์ ทำงานด้วย Python จึงโกงไม่ได้
เล่นคนเดียวหรือเล่นกับเพื่อนก็ได้ จากเบราว์เซอร์หรือมือถือ เป็นภาษาไทยหรืออังกฤษ

---

## 1. เปิดเกม

**Windows:** ดับเบิลคลิก **`Play.cmd`** ครั้งแรกมันจะติดตั้งสิ่งที่ขาดให้เอง แล้วเปิดเบราว์เซอร์

**ระบบอื่น:**

```bash
pip install -r requirements.txt
python launch.py
```

## 2. ใส่ AI ให้มัน

เกมต้องมีโมเดลมาเป็นผู้คุมเกม หน้าจอแรกจะบอกและมีลิงก์ให้ — วางคีย์ในแอปได้เลย
ไม่ต้องใช้หน้าต่างคำสั่ง

| | วิธี | ค่าใช้จ่าย |
|---|---|---|
| **Gemini** | **aistudio.google.com/apikey** → *Create API key* → วางในแอป | ฟรี ไม่ต้องใช้บัตร |
| **Claude Pro/Max** | ลิ้นชัก → **โต๊ะ** → *เข้าสู่ระบบด้วย Claude* | รวมอยู่ในค่าสมาชิกแล้ว |
| **Ollama** | ติดตั้งจาก **ollama.com** แล้ว `ollama pull llama3.2:3b` | ฟรี ใช้ออฟไลน์ได้ |

Claude เล่าเรื่องได้ดีที่สุด Gemini เริ่มได้เร็วที่สุด Ollama ไม่มีวันหมดโควตา

ถ้าตัวไหนหมดเครดิตกลางเกม ตัวถัดไปที่ใช้ได้จะรับช่วงต่อทันที และบอกให้รู้ในเนื้อเรื่อง

## 3. เล่น

สร้างตัวละคร แล้ว**พิมพ์สิ่งที่คุณทำ**เป็นภาษาปกติ:

```
ฉันแนบหูกับประตูแล้วฟัง
"ใครส่งแกมา?" — ฉันวางมือไว้ที่ด้ามดาบ
เทน้ำมันลงพื้นแล้วถอยไปทางบันได
```

ผู้คุมเกมจะตอบ ทอยเต๋าเมื่อกติกาต้องการ และอัปเดตใบตัวละครให้ ทุกการทอยจะแสดงให้เห็น:

```
เวสส์: ซ่อนตัว vs DC 14 · 1d20+3 → [7]+3 = 10
```

**ปุ่มต่าง ๆ บนหน้าจอ:**

- **★ มุมขวาบน** — ลิ้นชัก: **ตัวคุณ** (รูปตัวละคร บันทึกถึงผู้คุมเกม ทอยส่วนตัว)
  **ภาพ** (แกลเลอรี นำเข้าไฟล์ของคุณเอง) **โต๊ะ** (แชร์รหัส ส่งออก เลือก AI)
- **📎 ข้างช่องพิมพ์** — แนบรูป ผู้คุมเกมมองเห็นรูปนั้นด้วย
- **แถบสถานะเหนือช่องพิมพ์** — พลังชีวิต เกราะ และการทอยล่าสุด
- **☰ มุมซ้ายบน** — กลับหน้าหลัก
- **วิธีเล่น** ในหน้าหลัก — คู่มือสี่ขั้นตอน เปิดเองในครั้งแรก

## 4. เล่นกับคนอื่น

ลิ้นชัก → **โต๊ะ** → **แชร์รหัส** ส่งลิงก์ให้เพื่อน เขาสร้างตัวละครแล้วเข้ามาในเรื่องเดียวกัน
ได้สูงสุดหกคน ใครจะลงมือเมื่อไหร่ก็ได้ ไม่ต้องรอรอบ

**บนมือถือ** ที่ใช้ไวไฟเดียวกัน: เปิดที่อยู่ที่ตัวเปิดเกมพิมพ์ออกมา ส่วนจากที่ไหนก็ได้:

```bash
python launch.py --share --password "รหัสที่รู้กันแค่ในวงเรา"
```

จะได้ลิงก์สาธารณะสำหรับคืนนั้น มันจะไม่ยอมทำงานถ้าไม่ตั้งรหัสผ่าน — ลิงก์สาธารณะที่ไม่มีรหัส
ก็เหมือนเปิดบิลทิ้งไว้ให้ใครก็ได้มาใช้ AI ที่คุณจ่ายเงิน
